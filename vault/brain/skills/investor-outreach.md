# Investor Outreach & BD

## When to Use
Prospect research, investor pipeline management, cold outreach, partnership development.

## Tools Required
- ClickUp (pipeline tracking) — see clickup-tasks.md
- LinkedIn (prospect research) — see linkedin-research.md
- Gmail via browser/MCP (email outreach)
- Google Drive (pitch decks, partnership briefs)
- Apify (bulk prospect data collection)

## Pipeline Stages
1. **RESEARCH** — Scout identifies prospect, scores fit
2. **BRIEF** — Rex compiles prospect brief
3. **OUTREACH** — Draft email, Echo reviews copy, Jon approves before send from jon@ account
4. **FOLLOW-UP** — Every outreach gets follow-up (no exceptions)
5. **MEETING** — Schedule via Calendar (see calendar-scheduling.md)
6. **PROPOSAL** — Pitch deck via Google Slides
7. **CLOSE** — Contract via Lex review

## Prospect Scoring (Rex framework)
- Market fit (1-10)
- Portfolio relevance (1-10)
- Check size alignment (1-10)
- Geographic fit (MENA, Singapore, global)
- Total score: average, rank by total

## Email Rules
- Draft emails for Jon's review before sending from jon@ account
- Echo reviews copy before outreach
- Scout research first — always know the prospect before reaching out
- Follow-up cadence: Day 3, Day 7, Day 14
- Reference specific context (crypto 401k, Square BTC, MENA $1.2B market)

## Key Sources for Research
- FounderFirst.org, Magnitt, Forbes ME, FintechNews.ae, Fortune
- Top prospects (as of 2026-03-31): Dragonfly (10/10), Shorooq (9/10), STV (9/10), Paradigm (8/10), Polychain (8/10)

## Known Pitfalls
- Pipeline dies without consistent outreach — escalate if stalled >1 week
- Stagger API calls for bulk research to avoid 429s
- Real data only — never fabricate prospect interest or engagement
